# ICAIF 2026 Trading Agent Competition

Participant resources for the [ICAIF 2026 Trading Agent Competition on Codabench](https://hackathon2.deepintomlf.ai/competitions/99/).

## Official Starter Kit

Open the [`starter-kit`](starter-kit/) directory for setup instructions, schemas, examples, automatic submission tools, and the three manual upload templates:

- `register.json`
- `decision.json`
- `final_submission.json`

Download or clone the repository, then follow [`starter-kit/README.md`](starter-kit/README.md). Replace all placeholders with your own team information and credentials before uploading. Keep `.env`, `.icaif/`, team tokens, and private competition materials out of source control.
