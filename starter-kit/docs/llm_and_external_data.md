## Allowed LLMs and API Support

The use of large language models is optional. If an agent uses a large language model, it must use one of the supported models listed below:

- **Open-weight models:** Llama 4, Qwen3, DeepSeek-V3 / DeepSeek-R1, Gemma 3, Mistral Large.
- **Hosted API models:** OpenAI GPT-5 / GPT-5-mini, Anthropic Claude Opus 5 / Sonnet 5 / Haiku 4.5, Google Gemini 2.5 Pro / Flash, xAI Grok 4.

Teams using an LLM must disclose the model name, model version, provider, prompts, inference settings, and any relevant API configuration in their final materials.

Limited API credits for selected hosted models may be provided by **Nodexi Agentics, LLC**. Participants who wish to use these credits may apply to the organizers during the designated application period at the beginning of the competition. Availability is limited and is not guaranteed.

Participants using third-party hosted API services are responsible for complying with the applicable provider terms, privacy policies, and data-use requirements. Participants should not submit competition data or other materials to third-party services where doing so would violate applicable licenses, confidentiality requirements, or competition rules. The organizers are not responsible for the storage, processing, or retention practices of third-party service providers.

## News and External Data

- External market, company, and financial-news information must be freely and publicly accessible and must have been available at or before the corresponding submission deadline.
- Private, paid, proprietary, or non-public data feeds are not allowed.
- Recommended public sources include Yahoo Finance for financial news and SEC EDGAR for company filings and disclosures. These sources are provided as references and do not constitute a whitelist.
- Teams must document the external data sources and access methods used by their agents in their final materials.
- Participants are responsible for complying with the applicable licenses and terms of use of all external data sources.
